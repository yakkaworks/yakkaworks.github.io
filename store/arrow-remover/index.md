# Arrow Remover

**Versi Tidak disebutkan · Diperbarui 08-Aug-26**

## Deskripsi

Removes the default arrow markings from in-game one-way roads, alleys, and one-way bus roads for a cleaner and more minimalist appearance. It does not use plugin texture space, helping maintain compatibility and performance.
