# Panduan Instalasi Plugin TheoTown

Panduan ini ditujukan terutama untuk TheoTown di Android.

## Menggunakan file manager dalam game

1. Buka TheoTown dan masuk ke tampilan region.
2. Buka menu game lalu pilih **File Manager**.
3. Buka folder `plugins`.
4. Pilih **Import here**.
5. Pilih berkas atau folder plugin yang ingin dipasang.
6. Mulai ulang game agar perubahan diterapkan.

Pada versi TheoTown terbaru, berkas ZIP tidak selalu perlu diekstrak terlebih dahulu.

## Membuka berkas plugin dari aplikasi file manager

1. Temukan berkas `.ttplugin` atau `.plugin` yang telah diunduh.
2. Ketuk atau tekan lama berkas tersebut, lalu pilih **Open** atau **Open with**.
3. Pilih TheoTown dan lanjutkan untuk membuka berkas di game.
4. Jika diminta, konfirmasi pilihan aplikasi.

## Mengonversi ZIP menjadi plugin

Untuk ZIP yang perlu diimpor sebagai plugin, gunakan [halaman ekspor plugin TheoTown](https://forum.theotown.com/plugins/export), pilih berkas ZIP, tunggu proses selesai, lalu unduh hasilnya dan impor ke dalam game.

Jika langkah ini tidak sesuai dengan versi atau perangkatmu, lihat petunjuk instalasi pada [forum resmi TheoTown](https://forum.theotown.com/viewtopic.php?t=1354).
