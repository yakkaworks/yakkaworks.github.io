# TheoTown Plugin Installation Guide

This guide is primarily for TheoTown on Android.

## Using the in-game file manager

1. Open TheoTown and enter the region view.
2. Open the game menu and choose **File Manager**.
3. Open the `plugins` folder.
4. Choose **Import here**.
5. Select the plugin file or folder you want to install.
6. Restart the game to apply the changes.

Recent TheoTown versions may be able to import ZIP files without extracting them first.

## Opening a plugin through a file manager

1. Find the downloaded `.ttplugin` or `.plugin` file.
2. Tap or long-press it and choose **Open** or **Open with**.
3. Select TheoTown to open the file in the game.
4. Confirm the app choice if prompted.

## Converting a ZIP to a plugin

For ZIP files that need to be imported as plugins, use the [TheoTown plugin export page](https://forum.theotown.com/plugins/export), select the ZIP file, wait for processing, then download the result and import it into the game.

If these steps differ from your game version or device, check the [official TheoTown forum installation guidance](https://forum.theotown.com/viewtopic.php?t=1354).
