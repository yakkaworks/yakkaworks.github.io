# How to Install

Installing a Yakka Works TheoTown plugin only takes a few steps.

## Requirements

Before you start, make sure you have the *latest version* of TheoTown installed. Files marked as **encrypted** require the base game to unlock properly.

## Steps

- Download the plugin file from its Store page
- Open TheoTown and go to the plugin manager
- Import the downloaded file
- Restart the game if prompted

> If the plugin doesn't appear after import, try restarting TheoTown completely rather than just reloading the city.

Need the modification files instead of the compiled version? Check our [License page](/license.html) for what paid access includes.
