# Yakka Works Has Migrated to MkDocs

The Yakka Works website has recently migrated to MkDocs to provide a more accessible and reliable experience. The previous version relied heavily on JavaScript, which could make parts of the site difficult to read when JavaScript was disabled, including for automated tools and crawlers.

## A Fresh Start for the Library

This migration also marks a new beginning for the Yakka Works Library. It will be developed gradually into a collection of tutorials for TheoTown players who want to learn plugin creation, with Indonesian users being a particular focus. Some materials are still being written, so the current index also serves as a roadmap for upcoming content.

## Clearer Commission Information

Commission information is now presented with clearer terms. We have also introduced a price calculator to help estimate costs based on the selected starter package and add-ons. The result is only an initial estimate; complex requests may still require a direct consultation.

That concludes this update. Thank you for following Yakka Works!
