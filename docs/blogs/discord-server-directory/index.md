# Direktori Server Discord Komunitas TheoTown

Halo, sesama pembuat plugin dan pemain TheoTown!

Banyak pemain TheoTown kesulitan menemukan server Discord yang berkaitan dengan plugin dan komunitas yang lebih luas. Direktori ini dibuat agar server-server tersebut lebih mudah ditemukan, dengan menjaga sikap senetral mungkin. Daftar ini tidak dimaksudkan untuk mempromosikan atau memihak server, kreator, grup, persaingan, maupun konflik tertentu.

Kreator dipersilakan mengusulkan server mereka selama mematuhi Terms of Service dan EULA TheoTown maupun Discord.

Demi arsip dan kemudahan pencarian, server yang tidak aktif, sudah tidak digunakan, digabungkan, atau dihapus tetap dicantumkan beserta keterangannya. Sebagian tautan undangan mungkin sudah tidak berfungsi; servernya mungkin masih ada meskipun jarang dikelola atau digunakan.

**Terakhir diperbarui: 20 Oktober 2026**

> Ini adalah direktori komunitas, bukan dukungan atau endorsement terhadap server yang tercantum. Tautan undangan dan status dapat berubah; silakan laporkan koreksi jika ditemukan.

## Untuk Pemilik Server

Ingin server Anda ditambahkan? Kirim email ke [Yakka Works](mailto:yakkaworks@gmail.com?subject=Direktori%20Server%20Discord%20TheoTown) dengan nama server dan tautan undangannya. Tautan undangan permanen sangat disarankan.

Jika tautan undangan berubah, kirimkan tautan terbaru agar direktori dapat diperbarui. Anda juga dapat mengusulkan koreksi nama server atau status arsip.

Direktori ini dikelola untuk membantu penemuan komunitas dan keperluan arsip. Pencantuman server tidak berarti adanya afiliasi atau dukungan terhadap setiap server.
