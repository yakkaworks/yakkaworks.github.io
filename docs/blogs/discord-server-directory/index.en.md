# TheoTown Community Discord Server Directory

Hello, fellow plugin creators and players!

Many TheoTown players have difficulty discovering Discord servers related to plugins and the wider community. This directory aims to make those servers easier to find while remaining as neutral as possible. It is not intended to promote or favour any particular server, creator, group, rivalry, or conflict.

Creators are welcome to suggest their servers, provided they comply with the Terms of Service and EULA of both TheoTown and Discord.

For archival and discovery purposes, inactive, deprecated, merged, or deleted servers remain listed with a status note. Some invite links may no longer work; a server may still exist even if it is rarely maintained or used.

**Last updated: 20 October 2026**

> This is a community directory, not an endorsement of the listed servers. Invite links and statuses may become outdated; please report corrections when you notice them.
