# Kustom Presets Are Now Live

> Updates · 20-08-2026 · By Yakka

Our first batch of Kustom presets for KWGT and KLWP is available now.

The first batch of Yakka Works Kustom presets for KWGT and KLWP is now available. These presets are intended as starting points that users can apply and adapt to their own home-screen layouts.

KWGT is used to build custom widgets, while KLWP creates live wallpapers. Check each preset’s details and requirements before importing it, and make sure the corresponding Kustom app is installed.

This launch is an initial release rather than a promise that every preset will remain unchanged. Check the Store for current availability and follow future updates for additions or revisions.
