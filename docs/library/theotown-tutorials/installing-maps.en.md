# TheoTown Map Installation Guide

This community-based guide is for Android. Download the `.city` map file and copy it into TheoTown's `maps` folder. On many devices, the game's data folder is under `Android/data/info.flowersoft.theotown.theotown/files`; open TheoTown's data folder and then its `maps` folder. Reopen TheoTown to load the map.

Recent Android versions may restrict access to `Android/data`. If you cannot open that folder, use a file manager with suitable access support or follow instructions specific to your device. **Do not delete or overwrite your other city files when copying a map.**

Community reference: [TheoTown forum discussion about installing maps](https://forum.theotown.com/viewtopic.php?t=26944).
