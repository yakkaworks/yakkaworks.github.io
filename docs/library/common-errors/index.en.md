# Common Errors and How to Fix Them

> Troubleshooting · 05-02-2026 · By Guest Contributor

A running list of frequent plugin errors and what usually causes them.

When a plugin fails, start by identifying the exact symptom: it may not appear in the list, may load but render incorrectly, or may trigger an error. These symptoms point to different causes, so change one variable at a time.

Check the basics first: confirm the plugin is in the correct directory, required files are present, paths and file extensions match, and configuration files contain valid syntax. A missing comma, misspelled key, or unexpected value can prevent a file from being parsed.

If the plugin loads but looks wrong, verify texture dimensions, references, and any assumptions about the target object. Test after temporarily disabling related plugins to look for conflicts.

Keep a known-working copy and record the last change before testing. If the cause remains unclear, collect the error message, game version, plugin version, and steps to reproduce the issue before asking for help.
