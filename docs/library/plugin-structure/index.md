# Understanding Plugin File Structure

> Guides · 22-01-2026 · Oleh Yakka Works

How TheoTown plugin folders and files are organized, and why it matters.



Struktur folder merupakan bagian penting dari cara TheoTown menemukan dan memuat konten plugin. Simpan konfigurasi, tekstur, dan berkas pendukung pada lokasi yang sesuai dengan format plugin.

Nama dan jalur berkas harus konsisten. Perbedaan satu karakter, ekstensi, atau kapitalisasi dapat membuat referensi gagal di lingkungan tertentu. Hindari folder bertingkat yang tidak diperlukan.

Untuk memudahkan pemeliharaan, pisahkan aset sumber dari hasil generasi, gunakan nama deskriptif, dan catat perubahan penting. Jika membagikan proyek, sertakan berkas yang diperlukan dan jelaskan dependensi eksternal.

Jika plugin tidak muncul, periksa lokasi instalasi dan struktur direktori terlebih dahulu, lalu periksa sintaks dan pesan kesalahan game.
