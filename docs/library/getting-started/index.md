# Memulai Pembuatan Plugin TheoTown

Indeks ini mengelompokkan topik pembuatan plugin TheoTown. Setiap topik sudah memiliki halaman pengantar singkat; materi tutorial lengkap akan ditambahkan bertahap.

## Sebelum memulai

Hal penting yang perlu diperiksa sebelum membuat atau membagikan plugin.

- [Hak cipta dan atribusi](before-you-begin/copyright/index.md) — Pelajari dasar atribusi, sumber asli, dan hal yang perlu diperhatikan sebelum membagikan karya plugin.
- [Instalasi](before-you-begin/installation/index.md) — Pilih panduan untuk memasang plugin atau peta TheoTown. Langkah instalasi lengkap tersedia di halaman tutorial umum.
- [Perangkat lunak yang direkomendasikan](before-you-begin/recommended-software/index.md) — Daftar awal perangkat untuk mengedit JSON, menyiapkan gambar, memeriksa arsip, dan mengemas berkas plugin.


## Panduan pemula

Mulai dari struktur data JSON hingga membuat plugin TheoTown pertama.

- [Dasar sintaks JSON](beginner-guide/json-syntax-basics/index.md) — Kenali objek, array, string, angka, nilai boolean, koma, dan tanda kurung yang digunakan dalam berkas JSON.
- [Membuat plugin sederhana](beginner-guide/simple-plugin/index.md) — Ikuti gambaran awal tentang berkas dan nilai dasar yang dibutuhkan untuk membuat plugin kecil.


## Bangunan

Topik bangunan mencakup hunian, komersial, taman, industri, landmark, rumah sakit, kantor polisi, dan banyak jenis objek lainnya.

- [Plugin bangunan sederhana](buildings/simple-building-plugin/index.md) — Pengenalan struktur dasar untuk membuat satu bangunan di TheoTown.
- [Nilai plugin bangunan](buildings/building-plugin-values/index.md) — Ringkasan nilai konfigurasi yang menentukan tampilan, perilaku, dan informasi bangunan.
- [Persyaratan](buildings/requirements/index.md) — Pelajari cara menetapkan kondisi atau persyaratan agar bangunan tersedia atau berfungsi.
- [Peningkatan bangunan](buildings/upgrades/index.md) — Pengantar sistem peningkatan untuk menambahkan tahap atau kemampuan tambahan pada bangunan.
- [Bangunan nonpersegi](buildings/non-square-buildings/index.md) — Cara memikirkan ukuran dan tata letak bangunan yang tidak berbentuk persegi.
- [Komposisi](buildings/compositions/index.md) — Pengenalan komposisi untuk membangun objek dari beberapa bagian atau elemen.

- [Pejalan kaki](transport/pedestrians/index.md) — Gambaran objek dan perilaku pejalan kaki dalam lingkungan kota.
- [Bus](transport/buses/index.md) — Panduan dasar mengenai objek bus dan penggunaannya pada jaringan jalan.

- [Transport System Extension](transport/transport-system-extension/index.md) — Pengenalan plugin Transport System Extension dan hal yang perlu diperhatikan saat menggunakannya.
