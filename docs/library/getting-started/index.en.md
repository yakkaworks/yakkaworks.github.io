# Getting Started with TheoTown Plugins

This index groups TheoTown plugin-development topics. Each topic now has a short introductory page; full tutorials can be added incrementally.

## Before you begin

Things to review before creating or sharing a plugin.

- [Copyright and attribution](before-you-begin/copyright/index.md) — Review attribution, original sources, and the basics to consider before sharing a plugin.
- [Installation](before-you-begin/installation/index.md) — Choose the guide for installing TheoTown plugins or maps. The full step-by-step guides are in General TheoTown Tutorials.
- [Recommended software](before-you-begin/recommended-software/index.md) — An introductory list of tools for editing JSON, preparing images, inspecting archives, and packaging plugin files.
