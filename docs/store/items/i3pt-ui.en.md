# i3pt UI

> Version 1 • 25 Nov 2026

Inspired by the distinctive tiling window manager aesthetic of i3wm, i3pt UI brings a functional, minimalist look to TheoTown. Featuring a clean layout, sharp visual elements, and a utilitarian design language, this theme takes inspiration from the world of Linux desktop environments and brings a touch of that experience into the game.
