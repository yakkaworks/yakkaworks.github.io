# Panelki UI

> Version 1 • 25 Nov 2026

Panelki UI brings a simple yet modern appearance to TheoTown through its flat-colored and translucent interface elements. Combining subtle transparency with clean, solid surfaces, this theme creates a lightweight visual experience that keeps the interface looking organized without unnecessary decoration.
