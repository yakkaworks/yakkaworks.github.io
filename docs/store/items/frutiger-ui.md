# Frutiger UI

> Versi 1 • 28 Okt 2026

Frutiger UI terinspirasi dari estetika Frutiger Aero yang optimistis pada era 2000-an, memadukan permukaan mengilap, nuansa aqua, hijau cerah, dan efek kaca dengan penyesuaian kontras agar antarmuka tetap mudah dibaca.
