# Nature Plus (Web Exclusive)

> Version 1.3 • 28 Oct 2026

!!! note "Web-exclusive release"
    This plugin is marked as web-exclusive in the source catalogue.

Nature Plus, previously known as Nature+ or Cytopia Nature Pack, returns as a large environment collection containing approximately 30 flora items, 21 ground types, 7 water items, 25 decals, 5 colour decals, and 1 blueprint.
