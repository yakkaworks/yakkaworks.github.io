# Board UI (legacy) (formerly Oriental UI)

> Versi 1.2p

!!! info "Rilis lawas"
    Ini adalah tema Oriental UI versi lama. Board UI yang lebih baru tercantum sebagai produk terpisah.

Board UI (Legacy), yang sebelumnya bernama Oriental UI, mengubah tekstur antarmuka game ke gaya bernuansa abad pertengahan sehingga menu TheoTown terasa lebih seperti antarmuka permainan role-playing.
