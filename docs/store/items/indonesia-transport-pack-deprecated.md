!!! warning "Plugin deprecated"
    Pengembangan fitur untuk paket ini telah dihentikan dan pembaruan hanya ditujukan untuk pemeliharaan. Paket pengganti sedang direncanakan.

Nama file unduhan yang dicantumkan pada daftar sumber adalah `EXP_843` dan `EXP_842`, sedangkan katalog mencantumkan versi `8.4.5p`. Nama file dan versi katalog tidak sama, jadi periksa detail berkas sebelum memasangnya.
