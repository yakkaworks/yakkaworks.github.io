# Pastel UI (Legacy)

> Version 1p

!!! info "Legacy release"
    This is a legacy version. A newer related UI theme is available; see the related link below.

Pastel UI (Legacy) changes the game's interface textures with a style inspired by Material Design and Material You; its colours are selected from the available in-game palettes rather than changing dynamically.
