# Board UI (legacy) (formerly Oriental UI)

> Version 1.2p

!!! info "Legacy release"
    This is the former Oriental UI theme. The newer Board UI is listed separately.

Board UI (Legacy), formerly Oriental UI, changes the game's interface textures to a medieval-inspired style that gives TheoTown menus a more immersive role-playing-game appearance.
