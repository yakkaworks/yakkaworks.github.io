# Aria UI

> Version 1 • 25 Nov 2026

Aria UI introduces a minimal and distinctive interface style to TheoTown, featuring flat panels with selectively bordered corners instead of conventional full outlines. This subtle design approach creates a clean, structured appearance while giving interface elements a unique visual identity. Simple, understated, and designed for those who appreciate thoughtful UI details.
