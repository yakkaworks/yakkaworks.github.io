# NEETscape v3

> Versi 1 • 25 Nov 2026

NEETscape v3 is a minimalist, pixel-inspired Android homescreen and lock screen setup combining dithered imagery, custom KWGT widgets, modified icons, and carefully selected typography. Originally shared on r/androidthemes, it blends stock XOS elements with third-party customization tools. The complete setup files and components are available through the purchase link below.

## Komponen Setup

- **Wallpaper:** Kustom Komponent edit
- **Wallpaper layar kunci:** Sumber Reddit, telah diedit
- **Gambar widget:** Sumber Wallhaven, telah melalui dithering dan pemotongan
- **KWGT:** Widget kustom
- **Launcher:** Stock XOS
- **Paket ikon:** Lawnicons, dimodifikasi menggunakan Icon Pack Studio
- **Font:** M Plus 1 Code

## Persyaratan dan Aplikasi

- Pixellab
- Ditherit
- Shappky (memerlukan Shizuku)
- SD Maid
- KWGT (memerlukan KWGT Pro atau versi AOSP)
- Icon Pack Studio (Beta)
- Launchpad
- ZFont 3
