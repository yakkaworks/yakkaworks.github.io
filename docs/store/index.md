### Komisi { #commissions }

Membutuhkan plugin atau konten khusus? Baca [informasi komisi](commissions/index.md) atau hubungi [yakkaworks@gmail.com](mailto:yakkaworks@gmail.com).

### Website Exclusive Plugins { #website-exclusive-plugins }

Bagian ini diperuntukkan bagi plugin TheoTown eksklusif situs. Panduan pemasangan tersedia di [panduan instalasi plugin TheoTown](../library/theotown-tutorials/installing-plugins.md).

### TheoTown Maps { #theotown-maps }

Bagian peta akan memuat berkas kota yang diterbitkan untuk diunduh. Lihat [panduan instalasi peta TheoTown](../library/theotown-tutorials/installing-maps.md).

### Kustom { #kustom }

Bagian preset KWGT dan KLWP. Untuk impor preset, ikuti panduan resmi [KWGT](https://docs.kustom.rocks/docs/faq/faq_kwgt/) atau [KLWP](https://docs.kustom.rocks/docs/faq/faq_klwp/).

### Minecraft { #minecraft }

Bagian untuk konten Minecraft Bedrock. Lihat panduan resmi Microsoft tentang [mengimpor Add-On](https://learn.microsoft.com/en-us/minecraft/creator/documents/gettingstarted?view=minecraft-bedrock-stable).
