# Jasa Pembuatan Plugin TheoTown

**Dibuka untuk pesanan — mulai Rp35.000.** Punya ide plugin TheoTown sendiri, tetapi kesulitan menggambar sprite, mengatur konfigurasi, atau mengatasi error saat proses pembuatan? Yakka Works dapat membantu mewujudkannya.

Yakka Works telah membuat plugin TheoTown sejak 2020. Kami dipercaya sebagai Trusted Creator, memiliki kode privilege, dan menjadi bagian dari staf resmi TheoTown sebagai Discord Moderator.

Untuk perkiraan awal, gunakan [Estimator Harga Komisi](../../tools/commission-price-estimator/index.md). Harga akhir bergantung pada fitur, tingkat kesulitan, dan kelayakan teknis; konsultasikan kebutuhan sebelum memesan.

## Paket starter

### Bangunan dasar — Rp40.000 / US$5 (harga regional)

- Ukuran maksimal 4×4 petak.
- Maksimal 1 objek.
- Manifest disertakan.
- Gratis mode malam **atau** rotasi; memilih keduanya memerlukan biaya tambahan.
- Satu pengaruh dalam game dengan radius maksimal 16 petak.
- Maksimal 3 kali revisi.

### Kendaraan dasar — Rp35.000 / US$4,25 (harga regional)

Untuk kereta, bus, truk, atau mobil.

- Maksimal 2 objek.
- Mode malam dan rotasi disertakan.
- Manifest disertakan.
- Berfungsi sebagai transportasi kota.
- Maksimal 3 kali revisi.

## Kebijakan request

### Dapat dipertimbangkan

- NSFW, dengan beberapa pengecualian.
- Furry.
- Mecha.
- Konsep khusus lainnya selama memungkinkan dikerjakan.

### Tidak diterima

- Skyscraper, stadion, atau bangunan sejenis.
- Plugin dengan fitur overpowered (OP).
- Penghasilan dalam game yang berlebihan.
- Radius pengaruh yang berlebihan.
- Kapasitas yang berlebihan.

Beberapa NSFW kinks tidak diterima. Semua request bergantung pada kelayakan teknis dan keputusan kreator. Request yang tidak sesuai kebijakan dapat ditolak.

## Ketentuan pemesanan dan pembayaran

- Pesanan di bawah Rp60.000 tidak wajib membayar uang muka (DP).
- Pesanan mulai Rp60.000 wajib membayar DP sebesar 25%.
- Untuk pesanan tanpa DP, pembayaran dilakukan setelah plugin selesai dikerjakan.
- Metode pembayaran: QRIS, PayPal, Patreon, dan Ko-fi.

## Refund

Pembelian jasa bersifat **non-refundable** (tidak dapat di-refund). Pastikan semua detail pesanan dipahami dan disepakati sebelum pengerjaan dimulai.
