# Panduan Instalasi Peta TheoTown

Panduan komunitas berikut ditujukan untuk Android. Unduh berkas peta `.city`, lalu salin ke folder `maps` milik TheoTown. Pada banyak perangkat, folder data game berada di `Android/data/info.flowersoft.theotown.theotown/files`; buka folder data TheoTown, lalu folder `maps` di dalamnya. Buka ulang TheoTown untuk memuat peta.

Android versi baru dapat membatasi akses ke `Android/data`. Jika folder tersebut tidak dapat dibuka, gunakan file manager yang mendukung akses tersebut atau ikuti petunjuk yang sesuai untuk perangkatmu. **Jangan menghapus atau mengganti file kota lain saat menyalin peta.**

Rujukan komunitas: [diskusi instalasi peta di forum TheoTown](https://forum.theotown.com/viewtopic.php?t=26944).
