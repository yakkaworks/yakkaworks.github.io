# Pedestrian Expansion

**Versi 1p · Diperbarui 01-Aug-25**

## Deskripsi

Adds more variety to the pedestrians walking along sidewalks, making urban environments feel more lively and realistic. These pedestrians are part of the game's actual walking system rather than static decorative props.
