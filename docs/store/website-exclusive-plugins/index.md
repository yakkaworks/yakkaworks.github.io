# Website Exclusive Plugins

Plugin TheoTown yang diterbitkan secara eksklusif melalui situs Yakka Works akan dicantumkan di bagian ini. Gunakan [panduan instalasi plugin TheoTown](../../library/theotown-tutorials/installing-plugins.md) untuk memasang berkas plugin.
