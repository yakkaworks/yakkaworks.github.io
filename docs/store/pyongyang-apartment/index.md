# Pyongyang Apartment

**Versi 2p · Diperbarui 01-Aug-25**

## Deskripsi

A themed residential apartment pack inspired by real-life North Korean architecture seen in Pyongyang. It features 72 variations of a distinctive apartment style, with more variations planned for future updates.
