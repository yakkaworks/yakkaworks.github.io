# Diagonal Decals

**Versi 3p · Diperbarui 01-Aug-25**

## Deskripsi

Adds diagonal versions of in-game decals, including regular and shore-side variants. They provide smoother transitions and more natural-looking terrain and coastline details while retaining the game's native visual style.
