# Nature Plus

**Versi 1.3 · Diperbarui 28-Okt-26**

## Deskripsi

Nature Plus, plugin yang sebelumnya dikenal sebagai Nature+ atau Cytopia Nature Pack, kini kembali. Plugin ini berisi sekitar 30 flora, 21 ground, 7 waters, 25 decals, 5 color decals, dan 1 blueprint.
