## Pengembangan Plugin Kustom Lengkap

<small>Mulai dari **Rp100.000**. Harga akhir bergantung pada jenis plugin, fitur, kompleksitas, dan kebutuhan teknis.</small>

Layanan pembuatan plugin TheoTown dari awal, termasuk penyusunan aset, konfigurasi, dan fitur sesuai kesepakatan. Untuk kebutuhan yang sesuai dengan paket di bawah, harga paket tetap berlaku; harga mulai di atas merupakan indikasi umum untuk proyek kustom di luar paket dasar.

### Paket bangunan dasar — Rp100.000

- Ukuran maksimal 4×4 petak.
- Maksimal 1 objek.
- Manifest disertakan.
- Mode malam atau rotasi dapat dipilih tanpa biaya tambahan. Memilih keduanya memerlukan biaya tambahan.
- Satu pengaruh dalam game dengan radius maksimal 16 petak.
- Maksimal 3 permintaan revisi setelah hasil awal diserahkan.

### Paket kendaraan dasar — Rp80.000

Untuk kereta, bus, truk, atau mobil.

- Maksimal 2 objek.
- Mode malam dan rotasi disertakan.
- Manifest disertakan.
- Berfungsi sebagai transportasi kota.
- Maksimal 3 permintaan revisi setelah hasil awal diserahkan.

### Add-on dan fitur tambahan

| Fitur tambahan | Harga |
|---|---:|
| Ukuran bangunan di atas 4×4 petak | Rp15.000 per tingkat ukuran tambahan |
| Mode malam sederhana | Rp5.000 |
| Mode malam kompleks | Rp15.000 |
| Pengaruh dalam game — tambahan radius 16 petak | Rp5.000 per tambahan |
| Penghasilan bulanan | Rp20.000 per 100T |
| Objek di atas batas paket | Rp30.000 per objek |
| Fast Track / prioritas pengerjaan | Rp50.000 |

Harga add-on bergantung pada fitur dan tingkat kesulitan pengerjaan. Fitur bawaan paket dan add-on yang dipilih dapat memengaruhi total biaya. Estimasi awal bukan penawaran final; harga akhir dikonfirmasi setelah konsultasi.

## Pembuatan Gambar Plugin

**Rp30.000 per frame.**

Layanan pembuatan sprite atau gambar untuk plugin TheoTown. Setiap frame dihitung dan dikenakan biaya secara terpisah. Frame rotasi juga dihitung sebagai frame individual, sehingga jumlah frame yang diperlukan akan menentukan total biaya.

## Pembuatan JSON Plugin

**Rp20.000 untuk maksimal 2 file JSON.**

Layanan penyusunan file JSON untuk plugin TheoTown berdasarkan spesifikasi dan fitur yang telah disepakati. Dua file pertama termasuk dalam harga dasar. Setiap file tambahan dikenakan biaya **Rp5.000 per file**.

## Perbaikan JSON Plugin

**Rp15.000 untuk maksimal 2 file JSON.**

Layanan pemeriksaan dan perbaikan masalah pada file JSON plugin, selama masalahnya dapat ditangani berdasarkan file dan informasi yang diberikan. Dua file pertama termasuk dalam harga dasar. Setiap file tambahan dikenakan biaya **Rp5.000 per file**.

## Perbaikan Gambar Plugin

**Rp20.000 untuk maksimal 2 file gambar.**

Layanan perbaikan atau penyesuaian gambar plugin yang sudah tersedia, sesuai ruang lingkup yang disepakati. Dua file pertama termasuk dalam harga dasar. Setiap file tambahan dikenakan biaya **Rp5.000 per file**.

## Penanganan Penolakan Plugin Store

**Diagnosis awal gratis. Pengerjaan perbaikan mulai dari Rp35.000.**

Jika plugin ditolak oleh TheoTown Plugin Store, Yakka Works dapat membantu meninjau kemungkinan penyebab penolakan dan mengidentifikasi perbaikan yang diperlukan.

- Pemeriksaan dan diagnosis awal tidak dikenakan biaya.
- Pengerjaan perbaikan setelah diagnosis merupakan layanan berbayar.
- Rp35.000 adalah harga awal pengerjaan, bukan harga tetap untuk semua kasus.
- Biaya akhir ditentukan berdasarkan penyebab penolakan, kompleksitas, dan jumlah pekerjaan yang diperlukan.
- Persetujuan atau penerimaan plugin oleh TheoTown Plugin Store tidak dapat dijamin.

Pemesanan dan pengerjaan perbaikan mengikuti ketentuan komisi pengembangan plugin kustom lengkap, termasuk kebijakan permintaan, pembayaran, revisi, dan lisensi pada halaman ini.

## Pembuatan Peta Kustom

Pembuatan peta kota TheoTown berdasarkan konsep atau referensi yang disepakati. Dimensi peta harus mengikuti pilihan ukuran peta yang tersedia di dalam game TheoTown.

### Basic — Rp40.000

Pembuatan peta kustom dasar sesuai konsep dan ukuran yang tersedia di dalam game.

### Advanced — Rp50.000

Mencakup pembuatan jalan serta penempatan bangunan vanilla bawaan berukuran kecil, selain pembuatan peta dasar.

## Syarat dan Ketentuan

### Kebijakan permintaan

**Permintaan yang dapat dipertimbangkan:**

- NSFW, dengan beberapa pengecualian.
- Furry.
- Mecha.
- Konsep khusus lainnya selama memungkinkan untuk dikerjakan.

**Permintaan yang tidak diterima:**

- Skyscraper, stadion, atau bangunan sejenis.
- Plugin dengan fitur overpowered (OP).
- Penghasilan dalam game yang berlebihan.
- Radius pengaruh yang berlebihan.
- Kapasitas yang berlebihan.

Beberapa jenis konten atau kink NSFW tidak diterima. Setiap permintaan tetap bergantung pada kelayakan teknis, kemampuan, dan keputusan kreator. Yakka Works berhak menolak permintaan yang tidak sesuai kebijakan atau tidak memungkinkan untuk dikerjakan.
